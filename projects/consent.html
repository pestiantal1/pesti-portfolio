About

Consent is a narrative-driven horror game created for a game jam. Inspired by Papers, Please, it puts players in the role of a clinic worker making difficult decisions. Built entirely in GDScript using the Godot engine, it explores themes of autonomy and ethical dilemmas in a tense, atmospheric setting.
